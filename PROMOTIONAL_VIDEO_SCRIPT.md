## 🎨 PRODUCTION NOTES (Condensed)

### Visual Style:
- **Fast-paced editing** with smooth transitions
- **Color Scheme**: Blue (#0B4EDB), Green (success), Red (emergency)
- **Font**: Modern, Clean (Inter/Poppins)
- **Music**: Upbeat, energetic, community-focused

### Key Recording Requirements:
1. **Mobile Screen Recording**: 25 seconds of clean, fast-paced feature demonstration
2. **Desktop Recording**: 20 seconds of admin interface highlights
3. **B-Roll**: 20 seconds of community footage and drone shots
4. **Graphics**: 15 seconds of animated text overlays and logos

### Voiceover Guidelines:
- **Pace**: Energetic but clear (approximately 150-180 words per minute)
- **Bilingual**: Key phrases in both Tagalog and English
- **Tone**: Confident, community-focused, solution-oriented

### Editing Notes:
- **No dead time** - every second must add value
- **Quick cuts** between features (2-3 seconds each)
- **Split screens** for before/after comparisons
- **Animated text overlays** for key benefits
- **Seamless transitions** between mobile and desktop views
